# 문맥 범주 정의서

기획서 5.1의 4대 범주에 세부 성격(`sub_type`)을 더한 분류 기준이다. 변경할 때는 맨 아래 Change Log에 남긴다.

## 1. 메인 범주 (`category`)

가설 검증과 LLM-연구자 일치율(검증용 45조각)은 이 4개 범주 기준으로 산출한다.

| 범주 | 포함 기준 | 대표 키워드·맥락 |
| :--- | :--- | :--- |
| 종교·기원 | 교회 예배, 기독교적 성탄 메시지, 성탄절의 역사적·고대 기원 설명, 전통적 축복 표현 | `church`, `service`, `Christ`, `tidings`, 성탄 유래 칼럼 |
| 가정·사교·공동체 | 가족 모임, 만찬, 사교 파티·무도회, 학교·단체 행사, 자선·이웃 나눔 | `dinner`, `party`, `ball`, `children`, `charity`, 구세군 모금 |
| 상업·소비 | 상점의 연말 할인 광고, 선물 판촉, 상업적 인사말 광고, 상업화에 대한 논평 | `sale`, `gift`, `shop`, `store` |
| 시사·기타 | 전쟁·정치·사회적 사건, 단신·일정 안내, 위 세 범주에 속하지 않는 문맥 | 전쟁 위문품, 시사 논평, 날짜 표기 |

## 2. 세부 성격 (`sub_type`)

전체 데이터의 세부 경향을 보여주는 기술 통계와 원문 사례 발췌에 쓴다. 검증용 45조각으로는 `sub_type` 일치율을 산출하지 않는다.

| 범주 | `sub_type` | 포함 기준 |
| :--- | :--- | :--- |
| 종교·기원 | 예배·신학 | 교회 예배, 설교, 성탄 예배·캐럴 예배, 종교적 축복 |
| 종교·기원 | 기원·역사해설 | 성탄절 유래, 12월 25일의 역사, 로마·유대교 등 고대 기원 설명 |
| 가정·사교·공동체 | 일상·사교형 | 가족 식사, 파티, 무도회, 산타 방문, 학교·단체 성탄 행사, 개인 근황 |
| 가정·사교·공동체 | 자선·나눔형 | 구세군 모금, 구호 기금, 불우이웃 지원 |
| 상업·소비 | 판촉·광고형 | 백화점 세일, 선물 판촉, 상점 감사 광고 |
| 상업·소비 | 상업화 비판·성찰형 | 상업주의 경계, 물질보다 사랑·나눔을 강조하는 칼럼 |
| 시사·기타 | 시사·단신 | 시사 보도, 단신, 일정·공지, 날짜 표기로만 쓰인 `Christmas` |

## 3. 경계 사례 판정 규칙

- 구매를 권하는 광고는 문구가 따뜻하거나 종교적이어도 상업·소비/판촉·광고형으로 본다.
- 불우이웃 모금은 교회가 주관해도 자선·나눔형으로 본다. 교회 예배나 프로그램 자체는 예배·신학이다.
- 학교·지역사회 성탄 행사(암송, 노래, 연극)는 초점이 예배나 교리가 아니면 일상·사교형으로 본다.
- 뉴스나 공지에서 "크리스마스 전후" 같은 날짜 표지로만 쓰이면 시사·단신으로 본다.
- 여러 주제가 섞이면 키워드 `christmas`에 가장 가까운 주제를 따른다.
- OCR이 심하게 깨졌으면 읽히는 부분으로 판단하고 신뢰도를 낮음(low)으로 표시한다.
