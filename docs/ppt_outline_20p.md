# 발표 구성안 (20쪽): AI가 분류하고, 연구자가 검증했다 — 1900–1963 미국 신문 속 Christmas

- 작성: 2026-11-15, Claude Sonnet 5.5 (`claude-sonnet-5-5`) 초안 → 연구자 검토·승인
- 인용 수치·`snippet_id`는 `data/processed/`의 `summary_*_v0.3.csv`, `eval_mismatches_*.csv`, `ngram_*_v0.3.csv`, `discourse_representative_v0.3.csv`, `ngram_context_christmas_{day,tree}_v0.3.csv`와 보조로 `bias_adjusted_*.csv`에서 읽은 값임
- 표기: **[AI]** = AI가 수행한 처리, **[연구자]** = 연구자가 직접 설계·검수·해석한 부분
- 1960–63은 4개년 표본이므로 집계 표·그래프에 항상 `(4 yrs, n=71)`을 표기함

## 구성안 작성 전 확인 사항

1. **통계 표현의 한계.** `1920s 상업화 확장`은 일부만 데이터로 뒷받침된다. 상업·소비는 1900s 5.8% → 1910s 11.1% → 1920s 16.7% → 1930s 16.9% → 1940s 21.6%까지 오르지만, 1950s는 7.0%, 1960–63은 8.5%로 다시 내려간다. 따라서 "직선적 상업화"가 아니라 "1920s~40s에 높고 이후 낮아짐"으로 서술한다. 가정·사교·공동체도 1950s에 81.7%로 되돌아온다.
2. **기준선 표기.** 정확도 91.1%·κ 0.838은 검증 표본을 본 뒤 다듬은 v0.3 값이다(`summary_versions_v0.3.csv`에서 "탐색적 보정"). 공식 기준선은 v0.1의 88.9%·κ 0.786이며 슬라이드에는 둘을 함께 적는다.
3. **`year` 변수.** `kwic_snippets.csv`에는 `year` 열이 없고 `date`, `period`만 있다. 6쪽은 `date`로 적는다.
4. **지면 군집 편향.** `bias_adjusted_*.csv`를 7쪽과 18쪽의 보조 근거로 쓴다(지정 목록 밖의 파일).

  - [AI] 분류·근거 제공 / [연구자] 원문 대조로 의미 해석
- 시각화: 시기별 3열 카드(시기 / `snippet_id` / 15단어 이내 발췌 / AI 분류). 원문 출처는 `ngram_context_christmas_day_v0.3.csv`, `ngram_context_christmas_tree_v0.3.csv`, `discourse_representative_v0.3.csv`.
- 대본: 숫자 뒤의 문장을 직접 읽으면 `christmas day`는 주로 가정 방문과 식사, 일부는 예배 안내였습니다. `christmas tree`는 지역 행사에서 가정 장식으로, 때로는 유래 설명으로 쓰였습니다.

**15쪽. [RQ 답변] "RQ1·RQ2에 대한 답"**
- 본문
  - RQ1: 가정·사교가 가장 큰 범주지만 1920s(39.5%)와 1940s(22.7%)는 낮고 그때 종교(35.1%, 40.9%)가 높음. 상업은 1920s~40s에 상대적으로 높음. 단선적 세속화·상업화는 확인되지 않음
  - RQ2: `christmas day`·`christmas tree`는 전 시기 지속 표현이며 주로 가정·공동체 행사, 일부는 종교·기원 해설
  - 면 편향을 제외하면 시기 차이는 달라질 수 있음(18쪽 한계 참고)
- 시각화: 질문-답변 2칸 요약 카드와, 12쪽 100% 막대를 작게 재사용.
- 대본: 첫 번째 질문의 답은 "한 방향 변화가 아니라 시기별로 오르내린다"입니다. 두 번째 질문의 답은 핵심 표현이 계속 가정 행사 중심이지만 예배와 유래 설명으로도 쓰였다는 것입니다.

**16쪽. [검증 4단계] "연구자가 직접 확인한 신뢰도"**
- 본문
  1. [연구자 정답 45건 대조] 공식 기준선 v0.1: 정확도 88.9%, κ 0.786. v0.3: 91.1%, κ 0.838(탐색적, 표본을 본 뒤 보정). 전체 실행 안의 같은 45건 재채점은 93.3%, κ 0.876
  2. [반복 재현성] 같은 45건 재실행 일치 97.8%(44/45, 불일치 S0507)
  3. [저신뢰·경계 사례 점검] low 96건(12.2%). 1920s 28.1%, 1940s 23.9%로 높음. 남은 불일치 4건: S0507, S0526, S0369, S0362
  4. [N-gram 대조] 표면 표현과 AI 범주의 대응 확인(순환적이라 보조 근거)
  - κ는 "우연히 맞은 몫을 뺀 일치도"로 풀어 설명
- 시각화: `summary_versions_v0.3.csv` 정확도·κ 표, `summary_reproducibility_v0.3.csv` 일치율 게이지, `summary_period_confidence_v0.3.csv`의 시기별 low 비중 막대, `eval_mismatches_v0.3-presenter-rule.csv` 4건 표.
- 대본: 검증은 네 단계로 했습니다. 정답과 대조하고, 재실행해 보고, 확신이 낮은 사례를 직접 읽고, 표현 빈도와도 교차 확인했습니다. v0.3 수치는 표본을 본 뒤 다듬은 것이라 낙관적일 수 있어 공식 기준선도 함께 제시합니다.

## 05. 결론 및 시사점 (17–19쪽)

**17쪽. [요약과 의의] "AI의 규모 + 연구자의 검증이 만든 하이브리드 방법"**
- 본문
  - 발견: 가정·사교 중심 / 1920s·1940s에 종교·상업·시사가 상대적으로 큼 / 핵심 표현은 가정 행사 중심
  - 방법: [AI] 788건을 일관된 기준으로 분류 → [연구자] 기준 설계·오류 분석·원문 독해로 정확도 88.9% → 91.1%(탐색적)
  - 신뢰도 낮은 사례를 숨기지 않고 표시하는 분석 흐름 제시
- 시각화: 4개 핵심 발견 카드와 "AI ↔ 연구자" 역할 도식 재활용.
- 대본: AI만 쓰면 빠르지만 틀린 이유를 모르고, 사람만 하면 느립니다. 두 가지를 결합해서 속도와 검증 가능성을 함께 얻었다는 것이 이 연구의 방법론적 기여입니다.

**18쪽. [한계] "신문 지면 표집과 4개년 표본의 한계"**
- 본문
  - 시기당 5면: 한 면이 시기 표본의 25.3~32.8%
  - 지면 집중 점검(`bias_adjusted_leave_extreme_out.csv`): 1930s 종교·기원은 8.4%인데, 집중된 5면을 제외하면 28.0%. 1910s 가정·사교는 면 평균이 합산보다 11.7%p 낮음
  - 1960–63은 4개년이라 `(4 yrs, n=71)`이고 시기 간 직접 비교에 주의
  - v0.3은 검증 표본을 본 뒤 보정되어 정확도가 낙관적일 수 있음, 표본 지역이 몬태나·메인에 편중
- 시각화: `bias_adjusted_leave_extreme_out.csv`의 1930s·1910s 종교·기원 비율 "제외 0 / 1 / 3 / 5개" 선 비교.
- 대본: 시기별 차이의 일부는 어떤 지면이 뽑혔는지에 달려 있을 수 있습니다. 그래서 보정 분석으로 민감도를 점검했고, 1930s처럼 결과가 크게 달라지는 시기가 있다는 점을 한계로 밝힙니다.

**19쪽. [후속 연구] "기사 단위 분할과 표본 확대"**
- 본문
  - 면 대신 기사 단위로 분할해 집중 효과를 구조적으로 줄임
  - 시기·지역별 면 수 확대, 1960–63 표본 연도 확대
  - 정답 라벨을 45건에서 더 확대하고, 표본 밖 검증 세트로 규칙 평가
- 시각화: 현재(35면·45건) → 개선(기사 단위·확대 표본) 2단 로드맵.
